PERSONAL FINANCE MANAGER
========================

Project Description
-------------------
Personal Finance Manager is a web-based application used to manage
income, expenses, budgets and financial transactions.

Technology Used
---------------
Frontend:
- HTML
- CSS
- JavaScript

Backend:
- Node.js
- Express.js

Database:
- MySQL

How to Run the Project
----------------------

1. Make sure Node.js and MySQL are installed.

2. Open the project folder in VS Code.

3. Open a terminal and go to the backend folder:

   cd backend

4. Install the backend dependencies:

   npm install

5. Make sure the MySQL database is configured in:

   backend/db.js

6. Create/restore the database using:

   personal_finance_manager.sql

7. Start the backend:

   npm start

8. The backend should run on:

   http://localhost:3000

9. Open loginpage.html in a web browser.

10. Register a new account and log in.

Main Features
-------------
- User Registration
- User Login
- Logout
- Dashboard
- Income Management
- Expense Management
- Transaction History
- Edit Transactions
- Delete Transactions
- Budget Management
- Expense Analysis
- Financial Charts
- Financial Reports
- MySQL Database Storage
- User-specific Data

Database Tables
---------------
- users
- transactions
- budgets

Important
---------
The backend must be running before using the application.

The MySQL database must also be running.

The project is an executable web application and does not require
a PowerPoint presentation for demonstration.
